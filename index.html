Private, owner-operated software

GPU Guard

GPU Guard supports GPU monitoring notifications and operator-directed Google Workspace automation. It is a personal-use tool, not a public hosted monitoring service.

Google account access

The operator authorizes Google permissions through Google's consent screen. Depending on those permissions and the requested task, the software can work with Gmail, Calendar, Drive, Docs, Sheets and Contacts. Monitoring notifications use Gmail to send operational messages to an operator-designated recipient.

This website does not provide a Google sign-in form, accept account credentials, display monitoring data or offer public account registration.
